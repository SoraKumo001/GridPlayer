# GridPlayer

## 概要

GridPlayer は、複数の動画やアニメーション画像を一つのウィンドウで並列再生するためのメディアプレイヤーです。
ウィンドウサイズやファイルの比率に合わせて、最適なグリッドレイアウト（NxM）で自動的に配置します。

## 主な機能

- **並列再生**: 多数のメディアファイルをタイル状に並べて同時再生。
- **多様なフォーマット対応**: 通常の動画ファイルに加え、WebP や GIF などのアニメーション画像にも対応。
- **SkiaSharp による高速描画**: アニメーション画像の再生に SkiaSharp を採用し、低負荷・高品質なレンダリングを実現。
- **パフォーマンス最適化**:
  - 大解像度画像のデコードサイズ制限機能により、CPU/メモリ使用量を抑制。
  - プロセス優先度の自動調整（高優先度設定）による安定した再生。
- **直感的な操作**:
  - ファイルやフォルダをドラッグ＆ドロップするだけで即座に再生開始。
  - マウスホバーで表示される個別コントローラーとファイル名表示。
- **一括コントロール**: 全てのプレイヤーを同時に操作（一時停止、シーク、音量）可能。
- **レジューム再生**: 終了時の再生位置を記憶し、次回起動時に続きから再生。

## 操作方法 (ショートカット)

| キー                       | アクション                               |
| :------------------------- | :--------------------------------------- |
| **Space**                  | 全てのメディアを再生 / 一時停止          |
| **F** / **ダブルクリック** | フルスクリーン表示の切り替え             |
| **← / →**                  | 全てのメディアを 10 秒シーク (戻る/進む) |
| **↑ / ↓**                  | 全体の音量を調整                         |
